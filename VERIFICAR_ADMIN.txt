============================================================
COMO VERIFICAR SE O ADMIN JÁ EXISTE E SE O ACESSO ESTÁ OK
============================================================

O app identifica o admin pelo email sandrotattoo2222@gmail.com
marcado como is_admin = true na tabela public.profiles.

O acesso ao painel admin é feito tocando no ÍCONE DE ADMIN
(canto superior direito da tela inicial do app) e fazendo login
com email/senha.

Para o login funcionar, o usuário DEVE existir no Supabase Auth
(aba Authentication → Users).

------------------------------------------------------------
PASSO 1 — VERIFICAR SE O USUÁRIO EXISTE E SE É ADMIN
------------------------------------------------------------
Cole e execute no SQL Editor do Supabase:

  SELECT
    u.email,
    p.is_admin,
    u.confirmed_at IS NOT NULL AS email_confirmado
  FROM auth.users u
  LEFT JOIN public.profiles p ON p.id = u.id
  WHERE u.email = 'sandrotattoo2222@gmail.com';

INTERPRETAÇÃO:
- Se retornar 1 LINHA com is_admin = true  → admin OK, pode logar.
- Se retornar 1 LINHA com is_admin = false → o trigger não marcou;
  rode o PASSO 2.
- Se retornar 0 LINHAS → o usuário NÃO existe no Auth.
  Siga o PASSO 3.

------------------------------------------------------------
PASSO 2 — CORRIGIR is_admin (se o usuário existir mas não for admin)
------------------------------------------------------------
  UPDATE public.profiles
  SET is_admin = TRUE, atualizado_em = now()
  WHERE email = 'sandrotattoo2222@gmail.com';

------------------------------------------------------------
PASSO 3 — CRIAR O USUÁRIO ADMIN (se ainda não existir)
------------------------------------------------------------
Você pode criar de duas formas:

OPÇÃO A (recomendada, pelo painel):
1. Supabase → Authentication → Users → "Add user"
2. Email: sandrotattoo2222@gmail.com
3. Senha: ordnas565665
4. Salvar. O trigger cria o registro em profiles com is_admin = true.

OPÇÃO B (por SQL, se o Auth estiver com email confirmado liberado):
  SELECT supabase_auth.admin->>create_user'(
    '{
      "email":"sandrotattoo2222@gmail.com",
      "password":"ordnas565665",
      "email_confirm":true
    }'
  );

Depois rode o PASSO 1 de novo para confirmar is_admin = true.
