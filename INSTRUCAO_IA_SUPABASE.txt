# INSTRUÇÃO PARA A IA DO SUPABASE

**Cole a mensagem abaixo na aba "AI" (assistente de IA) do Dashboard do Supabase** e envie. Ela vai criar a tabela de estatísticas automaticamente.

## MENSAGEM PARA COLAR NA IA DO SUPABASE

```
Execute o seguinte script SQL no meu projeto. Crie a tabela "acessos" para registrar
as aberturas do meu app de karaokê, com RLS (INSERT público, SELECT só autenticado),
e crie a função RPC "stats_acessos" que retorna estatísticas de uso (hoje, 7 dias,
30 dias, total e histórico por dia). É seguro rodar mais de uma vez (idempotente).

SCRIPT:

CREATE TABLE IF NOT EXISTS public.acessos (
  id             BIGSERIAL PRIMARY KEY,
  dispositivo_id TEXT NOT NULL,
  criado_em      TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE INDEX IF NOT EXISTS idx_acessos_data ON public.acessos (criado_em);
CREATE INDEX IF NOT EXISTS idx_acessos_dispositivo ON public.acessos (dispositivo_id);

ALTER TABLE public.acessos ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "acessos_insert_public" ON public.acessos;
CREATE POLICY "acessos_insert_public"
  ON public.acessos
  FOR INSERT
  TO anon, authenticated
  WITH CHECK (true);

DROP POLICY IF EXISTS "acessos_select_auth" ON public.acessos;
CREATE POLICY "acessos_select_auth"
  ON public.acessos
  FOR SELECT
  TO authenticated
  USING (true);

GRANT INSERT ON public.acessos TO anon;
GRANT INSERT, SELECT ON public.acessos TO authenticated;

CREATE OR REPLACE FUNCTION public.stats_acessos()
RETURNS json
LANGUAGE sql
SECURITY DEFINER
SET search_path = public
AS $$
  SELECT json_build_object(
    'hoje',   (SELECT COUNT(DISTINCT dispositivo_id) FROM public.acessos
               WHERE criado_em >= date_trunc('day', now())),
    'semana', (SELECT COUNT(DISTINCT dispositivo_id) FROM public.acessos
               WHERE criado_em >= now() - interval '7 days'),
    'mes',    (SELECT COUNT(DISTINCT dispositivo_id) FROM public.acessos
               WHERE criado_em >= now() - interval '30 days'),
    'total',  (SELECT COUNT(*) FROM public.acessos),
    'por_dia', (
      SELECT COALESCE(json_agg(row_to_json(d)), '[]'::json)
      FROM (
        SELECT to_char(criado_em AT TIME ZONE 'America/Sao_Paulo', 'YYYY-MM-DD') AS data,
               COUNT(DISTINCT dispositivo_id) AS total
        FROM public.acessos
        WHERE criado_em >= now() - interval '7 days'
        GROUP BY data
        ORDER BY data DESC
      ) d
    )
  );
$$;

REVOKE ALL ON FUNCTION public.stats_acessos() FROM PUBLIC;
GRANT EXECUTE ON FUNCTION public.stats_acessos() TO authenticated;
```

## COMO TESTAR SE DEU CERTO

1. **No SQL Editor** (Dashboard → SQL Editor), rode:
   ```sql
   SELECT * FROM public.acessos ORDER BY criado_em DESC;
   ```
   Deve aparecer a tabela (pode estar vazia se ninguém abriu o app ainda).

2. **Testar a função** (no SQL Editor, como usuário autenticado):
   ```sql
   SELECT public.stats_acessos();
   ```
   Deve retornar um JSON com `hoje`, `semana`, `mes`, `total`, `por_dia`.

## OBSERVAÇÕES
- O app já está com o código pronto e **só vai registrar acessos depois que a tabela existir**.
- Se a tabela não existir, o app **continua funcionando normalmente** (o erro é silencioso).
- Após rodar o script, abra o app algumas vezes (ou peça para outras pessoas abrirem) para ver os números aparecerem no painel admin → aba **Estatísticas**.
